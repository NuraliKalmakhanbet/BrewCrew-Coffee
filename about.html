Our story

BrewCrew started as a university project and became our favourite way to practise web development.

We planned the pages together, split the work between three people and tested everything on phones and laptops. Every assignment added something new: first HTML, then CSS and Bootstrap, then JavaScript, and now accounts, ratings, a working cart and live data from an API.

How we built it

  1. Formulated the concept and the page structure
  2. Designed the colour scheme with light and dark themes
  3. Wrote semantic HTML5 and responsive Bootstrap layouts
  4. Added JavaScript: accounts, validation, search, ratings, cart and the coffee API
  5. Published the site with GitHub Pages
