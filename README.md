# BrewCrew Coffee

A clean, multi-page website for a coffee shop.

## Authors

- **Nurali Kalmakhanbet** — Home (`index.html`), About Us (`about.html`)
- **Zhumak Zhalgas** — Menu (`menu.html`), Contact (`contact.html`)

## Tech Stack & Features

- **Core Components:** Custom navigation menu, interactive contact form, price table, and profile cards.
- **CSS Selectors & Layout:** Implements flexbox, custom spacing, hover states, and responsive media queries (Bootstrap removed in favor of pure custom CSS).
- **JavaScript Features:** Client-side form validation, FAQ accordions, pop-up modal forms, dynamic background color switcher, and real-time date/time display.
